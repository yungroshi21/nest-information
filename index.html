Home Assistant Nest Integration connects the owner's Google Nest thermostat to their privately operated Home Assistant installation.

What the integration does

With the owner's Google authorization, the integration reads thermostat temperature, humidity, operating mode and temperature settings. It allows the owner to adjust supported thermostat settings from Home Assistant and receive device updates through Google Cloud Pub/Sub.

Who it is for

This is a personal household project, not a public sign-up service. This website provides information about the integration. It does not provide access to the thermostat or the owner's Home Assistant installation.

Data and permissions

The owner selects which supported Nest devices to connect through Google's permission screens. Home information may include home and room names and postal code. Read the privacy policy for details about access, storage and revocation.

Support

Household users should contact the owner who configured their Home Assistant access. This project is independently operated and is not an official Google or Home Assistant service.
